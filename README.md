# WantbeFree Homebrew Tap

Homebrew tap for WantbeFree macOS apps.

## MicLock

Install MicLock:

```bash
brew tap WantbeFree/tap
brew install --cask miclock
```

MicLock is a native macOS menu bar app that keeps macOS on the right microphone so AirPods, Sony WH-1000XM, and other Bluetooth headsets do not switch into low-quality headset mode.

Repository: https://github.com/WantbeFree/MicLock
